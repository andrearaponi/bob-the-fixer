## What's New

Bob learns to **write back**. Until now Bob could scan your code and hand your assistant fix-ready context, but a decision — *this is a false positive*, *this hotspot is safe* — lived only in a throwaway report and was lost on the next scan. This release closes that loop, adds a full dependency-security surface, and ships agent skills for four coding agents. **21 → 27 MCP tools.**

### Close the loop: verdicts that persist

| Tool | What it does |
|------|--------------|
| **`sonar_transition_issue`** | Persist a verdict: `confirm`, `resolve`, `falsepositive`, `accept`, `reopen` — with an optional rationale comment |
| **`sonar_comment_issue`** | Attach an auditable rationale to an issue |
| **`sonar_change_hotspot_status`** | Complete a hotspot review: `REVIEWED` with `SAFE`, `FIXED`, or `ACKNOWLEDGED` |

Verdicts that **hide** a finding (`falsepositive`, `accept`, hotspot `SAFE`) require an explicit `confirm: true`, validated before any request leaves your machine. Permission failures name the exact SonarQube permission you are missing, and your token never appears in an error message.

### Dependency security with Trivy

- **`trivy_scan_dependencies`** — vulnerabilities enriched with the full dependency path (`Via:`), **the direct dependency you should actually bump** (not the transitive), and reachability triage: *imported in source* vs *dormant*
- **`trivy_check_installation`** — availability and version check with install hints
- **`trivy_generate_sbom`** — CycloneDX / SPDX SBOM generation

### Agent skills

Three workflow playbooks, installed automatically for every coding agent the installer detects — **Claude Code, Gemini CLI, Codex CLI and now GitHub Copilot CLI**:

- **`bob-zerodebt`** — drive technical debt to zero in a measured loop: baseline → triage → batched fixes → re-scan → delta report
- **`bob-issuecoverage`** — close coverage gaps with behavior-asserting tests
- **`bob-securitysweep`** — sweep all three security surfaces, with a guided hotspot review whose verdicts stay human and are now **persisted to SonarQube**

### Under the hood

- The SonarQube client God object shrank from **3,288 to 373 lines** (−89%), split into focused modules with full-suite parity at every step
- **All 63 known npm vulnerabilities resolved** (63 → 0), kept that way by a Trivy gate in CI
- CI hardened: `npm ci`, a supported-Node matrix (20.x / 22.x), an ESLint gate and a security gate
- Bob now reports its real version over MCP instead of a hardcoded `2.0.0`
- **1559 tests** passing
